# Tareas de agentes

Cada carpeta es una tarea creada con `quality/tarea.mjs`. Contiene `tarea.md` y
`bitacora.jsonl`, que solo admite eventos nuevos. No se edita a mano: el gate
`Tareas` rehace la historia y falla si deja de ser legal.

Las reglas están en [el protocolo de agentes](../agentes/PROTOCOLO.md).
